# Features

## Core Features

### 🔍 NFC Record Detection
Automatically detect when records are placed on the shelf using NFC technology. The system reads record metadata and initiates playback.

### 🎵 Audio Playback
- Support for multiple audio formats (MP3, FLAC, WAV, etc.)
- Seamless playback integration
- Volume control and playback management
- Playlist management

### 📸 Visual Projection
- Dynamic album artwork display
- Real-time metadata projection
- Customizable visual themes
- Visual effects and transitions

### 🎛️ User Interface
- Intuitive shelf-based interaction
- Physical record placement for control
- Optional web-based remote control (if applicable)
- Status indicators and feedback

## Advanced Features

### 📚 Record Database
- Automatic metadata lookup
- Custom record database support
- Album artwork integration

### 🔧 Customization
- Configurable themes and layouts
- Custom music directories
- Extensible plugin system (if applicable)

### 📊 Statistics
- Playback history tracking
- Most-played albums
- Usage analytics (if applicable)

## Hardware Features

- **Shelf Design**: Purpose-built for vinyl records
- **NFC Integration**: Reliable record detection
- **Projection Capability**: Compatible with standard projectors
- **Audio System**: Integrated or external audio options
