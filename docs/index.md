# Vinyl Projection Mapping Player

Welcome to the Vinyl Projection Mapping Player project! This is a custom vinyl shelf with an integrated NFC reader that automatically plays records and projects album artwork and metadata.

## Quick Overview

This project combines the analog experience of vinyl records with modern projection technology:

- **NFC Reader**: Automatic detection when records are placed on the shelf
- **Music Playback**: Seamlessly plays selected vinyl records
- **Visual Projection**: Displays album artwork and metadata on a projection surface
- **Custom Hardware**: Purpose-built shelf designed for vinyl records

## Features

✨ Automatic record detection via NFC  
🎵 Integrated music playback system  
📸 Dynamic album art and metadata projection  
🎛️ Custom shelf design  
🔧 Easy to modify and extend
