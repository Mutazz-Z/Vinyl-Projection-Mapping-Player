# Vinyl Projection Mapping Player

A fun, artistic, futuristic way to display and _play_ your vinyl records. 

## Hardware Used

| Hardware | Use | Image | 
| -------- | --- | ----- |
| Raspberry Pi 4 | Runs the orchestrator, web app, and displays visuals to shelf | |
| ESP8266 | Brains for the NFC Reader | |
| PN532 | Actual NFC Reader/Writer |
| Projector | To project visuals to shelf | |
| Custom Shelf | To mount the ESP/NFC Reader to for scanning your records | |
