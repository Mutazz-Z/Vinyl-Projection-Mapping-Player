# Contributing

We love contributions! Whether it's bug reports, feature requests, or code improvements, all are welcome.

## How to Contribute

### Reporting Bugs
1. Check if the bug has already been reported in [Issues](https://github.com/yourusername/Vinyl-Projection-Mapping-Player/issues)
2. If not, create a new issue with:
   - Clear description of the bug
   - Steps to reproduce
   - Expected vs actual behavior
   - Your system information (OS, Python version, hardware)

### Suggesting Features
1. Check existing [Issues](https://github.com/yourusername/Vinyl-Projection-Mapping-Player/issues) and [Discussions](https://github.com/yourusername/Vinyl-Projection-Mapping-Player/discussions)
2. Create a new issue with:
   - Clear feature description
   - Use cases and benefits
   - Any relevant examples or references

### Contributing Code

1. **Fork the repository** on GitHub
2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes**
   - Follow the existing code style
   - Add tests if applicable
   - Update documentation
4. **Commit your changes**
   ```bash
   git commit -m "Add your descriptive commit message"
   ```
5. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request**
   - Describe what your changes do
   - Reference any related issues
   - Wait for review

## Development Setup

```bash
# Clone your fork
git clone https://github.com/YOUR_USERNAME/Vinyl-Projection-Mapping-Player.git

# Create virtual environment
python -m venv venv
source venv/bin/activate

# Install development dependencies
pip install -r requirements-dev.txt
```

## Code Style

- Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/) for Python code
- Use meaningful variable names
- Add comments for complex logic
- Keep functions focused and modular

## Testing

Before submitting a pull request, ensure:
- [ ] Code runs without errors
- [ ] New features have tests
- [ ] Documentation is updated
- [ ] No breaking changes to existing functionality

## Questions?

- Open a [Discussion](https://github.com/yourusername/Vinyl-Projection-Mapping-Player/discussions)
- Feel free to ask in any pull request or issue
